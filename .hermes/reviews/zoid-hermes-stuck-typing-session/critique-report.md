# Critique Report: Zoid Hermes stuck typing session fix

## Verdict

APPROVED

## Summary

The final R2 fix resolves the remaining unsafe session behavior from the prior critique. New normal Zoid Hermes chats no longer use shared `--continue` flow; later sends in the same Zoid chat pass the stored Hermes CLI session id and resume that exact session. R1 and R3 remain resolved: the frontend production build passes, and the standard test command passes with Rust lib/bin tests instead of unsupported doctests.

The Hermes stuck-typing/session behavior is safe to approve based on code inspection, targeted Rust coverage, full build/test gates, and a real Hermes CLI smoke test using the same first-chat/no-continue and later-chat/resume argument shape.

## What was changed

- `src/agents/AgentsHermesScreen.tsx`: `HermesChatSession` now carries optional `hermesCliSessionId`; sends pass `activeSession.hermesCliSessionId`; successful responses persist `response.session`; failures replace the streaming placeholder with an error-state assistant message instead of leaving an empty `HERMES WRITING` bubble forever.
- `src/agents/hermesClient.ts`: `sendHermesCliMessage` accepts optional `hermesSession` and invokes Tauri with `{ messages, linkedRepository, hermesSession }`, matching the Rust command's `hermes_session` argument.
- `src-tauri/src/lib.rs`: `send_hermes_cli_message` accepts `hermes_session`; first normal chats call `hermes chat --quiet --source desktop --query ...` with no `--continue`; later normal chats with a stored session call `hermes chat --resume <session_id> --quiet --source desktop --query ...`; output parsing extracts `session_id:` / `Session ID:` and returns the parsed id to the frontend.
- `src-tauri/src/lib.rs`: direct terminal-style prompts such as `hermes tools list` still bypass the normal chat wrapper and are not accidentally session-resumed.
- `package.json`: `test:rust` runs `cargo test --manifest-path src-tauri/Cargo.toml --lib --bins -- --test-threads=1`, avoiding unsupported doctests while keeping the relevant Rust suite in `npm test`.
- Handoff-listed gate-fix files remain present for broader dirty-tree build/test compatibility.
