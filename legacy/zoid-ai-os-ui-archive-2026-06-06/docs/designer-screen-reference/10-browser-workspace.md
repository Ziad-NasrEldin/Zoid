# Browser Workspace Screens

## Browser Workspace
Components:
- Browser header: back, forward, reload, address/search, new tab, save page, screenshot, link entity, more
- Tab bar
- Webview area
- Optional verification panel
- Right inspector
Actions: New Tab, Bookmark, Save Page to Note, Summarize, Extract Key Points, Save Screenshot, Link Page, Start Verification, Capture Console.

## Saved Pages
Components:
- Search/filter toolbar
- Saved pages list: title, URL, saved at, linked entities, screenshot status, summary
- Saved page inspector
Actions: Open, Link Entity, Summarize, Create Note, Delete.

## Screenshots / Captures
Components:
- Search/filter toolbar
- Captures grid/list: name, source URL, captured at, linked entity, path
- Capture preview inspector
Actions: Open, Link Entity, Reveal in Files, Delete.

## App Verification Session
Components:
- Session header: target URL, linked product/repo/launch gate, run button
- Verification checklist
- Evidence list
- Results summary
Actions: Run Checks, Save Evidence, Link to Launch Gate, Mark Passed/Failed, Create Fix Task.
