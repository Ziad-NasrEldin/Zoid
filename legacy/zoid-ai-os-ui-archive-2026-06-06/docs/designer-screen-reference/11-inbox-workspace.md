# Inbox Workspace Screens

## Inbox Dashboard
Components:
- Header: Search Inbox, Connect Gmail, Compose Email, Mark Resolved, Settings
- Summary cards: urgent items, approvals, failed automations, agent blockers, Gmail
- Attention feed
- Approval queue
- Gmail summary
- Calendar/task reminders
- Content publishing status
- Recent notifications
- Right inspector

## All Attention Items
Components:
- Search/filter toolbar
- Attention list: title, type, workspace, severity, linked entity, created, status
- Item inspector
Actions: Open, Resolve, Snooze, Create Task, Link Entity, Retry.

## Review Approvals
Components:
- Review filters
- Review queue: entity, proposed action, verdict, evidence, required fixes, created
- Review inspector
Actions: Open Review, Open Entity, View Evidence, Approve and Continue, Require Fixes, Create Fix Task, Re-run Review.

## Gmail
Components:
- Gmail header: connection, search, compose, refresh, settings
- Message list
- Thread preview/detail
- Draft reply area
- Email metadata inspector
Actions: Connect, Search, Refresh, Open Thread, Summarize, Draft Reply, Compose, Send, Link Contact/Company, Convert to Task.

## Compose Email
Components:
- Compose header
- To / CC / BCC / Subject / Body fields
- Context panel
- Footer actions
Actions: Save Draft, Discard, Request Review, Send after Confirmation.
