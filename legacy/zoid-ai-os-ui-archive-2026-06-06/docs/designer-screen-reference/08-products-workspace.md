# Products Workspace Screens

## Products Dashboard
Components:
- Header: Search Products, New Product, New Roadmap Item, Settings
- Summary cards: active products, needing attention, upcoming launches, active tasks
- Product list
- Roadmap preview
- Launch timeline
- Product tasks
- Linked deployments
- Product history
- Right inspector

## All Products
Components:
- Search/filter/sort toolbar
- Product list: name, status, type, owner, repos, tasks, deployments, releases, activity
- Product preview inspector
Actions: New Product, Open, Create Task, Link Repo, Link Content, Add Decision, Run Launch Gate.

## Product Detail
Components:
- Detail header
- Tabs: Overview, Roadmap, Tasks, Repos, Deployments, Releases, Notes/Decisions, Content, Automations, Clients/Companies, Timeline/History
- Right inspector
Actions: Edit Product, Create Task, Link Repo/Note, Add Decision, Add Roadmap Item, Create Release, Run Agent.

## Product Roadmap / Releases
Components:
- Roadmap board/list by status
- Deployments list with URLs and verification records
- Releases list with commits, PRs, launch gates, evidence
Actions: New Roadmap Item, Mark In Progress/Done, Verify Deployment, New Release, Mark Released.
