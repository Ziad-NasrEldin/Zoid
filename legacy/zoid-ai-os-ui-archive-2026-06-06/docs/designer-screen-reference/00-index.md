# Zoid Designer Screen Reference

Minimal screen/component checklist for design handoff.

Use this as acceptance reference: each delivered screen should include the listed shell areas, primary content blocks, and obvious actions. Details, copy, styling, colors, typography, and motion are intentionally excluded.
