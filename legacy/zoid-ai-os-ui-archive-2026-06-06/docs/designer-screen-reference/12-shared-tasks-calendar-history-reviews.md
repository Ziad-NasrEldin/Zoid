# Shared System Screens

## Tasks
Components:
- Header: Search, New Task, Filter, Sort, View Toggle
- Status navigation
- Task list/board
- Task detail inspector
Actions: Start, Mark Done, Block, Needs Review, Archive, Start Agent, Link Entity, Add Note, Delete.

## Task Detail
Components:
- Header: title, status, priority, due date, actions
- Description
- Checklist/subtasks
- Linked entities
- Agent runs
- Review records
- Comments/notes
- History

## Calendar
Components:
- Header: view switcher, date navigation, New Event, Sync Apple Calendar, Settings
- Calendar body: events, due dates, publishing slots, automation schedules, reminders, follow-ups, launches
- Calendar item inspector
Actions: New Event, Sync, Link, Check Conflict, Edit, Delete, Open Source.

## History
Components:
- Header filters
- Event timeline
- Event inspector
Actions: Open Event, Open Entity, Export, Copy Summary, Create Task, Link Entity.

## Reviews
Components:
- Header filters and New Review
- Review list
- Review detail: entity, verdict, reviewer, evidence, fixes, linked events/tasks
Actions: Approve and Continue, Create Fix Task, Re-run Review, Archive.
