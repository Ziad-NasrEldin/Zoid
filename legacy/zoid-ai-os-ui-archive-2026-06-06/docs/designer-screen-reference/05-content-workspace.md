# Content Workspace Screens

## Content Dashboard
Components:
- Header: Search Content, New Content Piece, New Content Plan, Generate Today’s Content, Settings
- Summary cards: planned today, drafts, needs review, scheduled, failures
- Content calendar preview
- Active pipeline items
- Review queue
- OmniSocials status
- Asset queue
- Publishing history
- Right inspector

## Content Calendar
Components:
- Calendar controls
- Daily slots
- Pipeline slots
- Scheduled/failed posts
- Queue sidebar
- Slot/item inspector
Actions: New Piece, Generate, Reschedule, Review, Upload Media, Schedule, Verify.

## Content Plans
Components:
- Plan list with status, date range, pieces, platforms, activity
- Plan inspector
- Detail screen: objective, pillars, planned pieces, calendar placement, assets, reviews, publishing, history
Actions: New Plan, Generate Pieces, Add Piece, Link Product/Notes, Archive, Create Task.

## Content Pieces
Components:
- Piece list with title, type, status, platforms, schedule, review state, publishing state
- Piece detail header
- Pipeline status bar
- Tabs: Brief, Draft, Assets, Captions, Platform Adaptations, Review, Publishing, Verification, History
- Right inspector
Actions: Generate Draft/Assets, Attach Asset, Send to Review, Upload Media, Schedule, Publish, Verify, Duplicate, Archive.

## Asset Library
Components:
- Search/filter toolbar
- Asset grid/list: name, type, linked content, path, upload status, last used
- Asset inspector
Actions: Add, Generate, Open, Link, Upload, Reveal, Delete.
