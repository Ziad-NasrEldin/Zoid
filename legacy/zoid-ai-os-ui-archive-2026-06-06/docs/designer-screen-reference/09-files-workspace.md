# Files Workspace Screens

## Files Dashboard
Components:
- Header: Search Files, Add Folder, New Folder, Settings
- Summary cards: pinned folders, Zoid folder, recent files, linked files
- Folder shortcuts
- Recent files list
- Content assets
- Browser captures
- Repo folders
- File events
- Right inspector

## File Explorer
Components:
- Path bar: back, forward, up, breadcrumbs, search, new folder, more
- Left folder tree
- Main file list: name, kind, size, modified, linked entity, repo status
- Preview pane
- Right inspector
Actions: Open, Preview, Rename, Move, Copy, Duplicate, Delete, New Folder, Reveal, Link Entity, Copy Path.

## File / Folder Detail
Components:
- Header: name, type, path, quick actions
- Metadata
- Preview
- Linked entities
- Repo-aware status if applicable
- Events
- Actions section
