# Automations Workspace Screens

## Automations Dashboard
Components:
- Header: Search, New Automation, Run Selected, Settings
- Summary cards: enabled, running, failed, upcoming
- Automation list
- Failed runs
- Upcoming schedule
- Recent runs
- Default automations panel
- Right inspector

## All Automations
Components:
- Search/filter toolbar
- Automation list: name, workspace, type, schedule, enabled, status, last run, next run, result
- Automation preview inspector
Actions: New, Run Now, Pause/Resume, Retry Failed, Change Schedule, View Logs.

## Automation Detail
Components:
- Detail header
- Tabs: Overview, Schedule, Runs, Logs, Linked Entities, Failure Policy, History
- Right inspector
Actions: Edit, Run Now, Pause/Resume, Create Task, View Failures.

## Automation Run Detail
Components:
- Run header
- Trigger
- Inputs
- Outputs
- Errors
- Logs
- Linked task/entities
- Events
- Run metadata inspector
Actions: Retry, View Logs, Create Fix Task, Link Entity.
