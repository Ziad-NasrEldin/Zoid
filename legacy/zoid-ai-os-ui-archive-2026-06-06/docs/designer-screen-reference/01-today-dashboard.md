# Today Dashboard

## Purpose
Daily operating surface for priorities, blockers, active work, calendar, content, agents, repos, automations, Gmail, and history.

## Required layout
- Global desktop shell
- Workspace header: title, date, search, New Task, Start Agent, Refresh Brief, Configure Widgets
- Top priority row
- Main operations grid
- Secondary operations grid
- Right inspector for selected item

## Components
- AI Daily Brief card
- Needs Attention card
- Active Work card
- Today Tasks widget
- Calendar widget
- Content Queue widget
- Active Agents widget
- Dirty / Attention Repos widget
- Automation Failures widget
- Gmail Summary widget
- Recent History widget

## Key actions
- Open item
- Review
- Resolve / snooze
- Start agent
- Create task
- Refresh
