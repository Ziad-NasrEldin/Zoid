# Global Shell and Modals

## App Shell
Required areas:
- Left sidebar
- Main workspace area
- Right inspector panel
- Sessions panel
- Global overlays

## Left Sidebar
Sections:
- Workspace switch area
- Primary workspaces: Today, Code, Agents, Notes, Content, Automations, Business, Products, Files, Browser, Inbox
- Current focus: active task, agent run, product, repo
- Utilities: Tasks, Calendar, History, Notifications, Settings, Local Profile

## Workspace Header
Components:
- Title
- Breadcrumb/context
- Search
- Scope/filter controls
- Primary action
- Secondary actions
- View toggle
- Refresh
- More menu

## Right Inspector
Components:
- Selected entity header
- Metadata
- Linked entities
- Review/permission state
- Recent activity
- Inspector actions

## Sessions Panel
Components:
- Session header
- Clean / Raw tabs
- Clean conversation cards
- Raw terminal output
- Input/footer actions
Actions: New Session, Attach Context, Run/Send, Stop, Retry, Request Review, Open Logs, Link Entity.

## Global modals
- New Task
- New Note
- Start Agent Run
- Link Entity
- Confirmation
- Review Gate
- File Picker
- Permission Prompt

## Confirmation rule
Any publishing, deployment, destructive, external-send, or data-changing integration action needs a confirmation screen with affected items and risk summary.
