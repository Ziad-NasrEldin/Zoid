# Feature Handoff: P2 UI isolated components batch

## Original request

Use the Zoid-wide subagent workflow to finish multiple things at once. After completing P2.20 and P2.28-P2.30, the next safe parallel lanes were isolated frontend components/view-models for:

- P2.21 task create/list/detail UI foundation.
- P2.26 notification/Inbox attention card basics.
- P2.27 History view for task/run events.

This batch intentionally avoids `src/App.tsx` integration so the parallel lanes do not conflict. Do **not** treat P2.21/P2.26/P2.27 tracker items as fully complete until native/App integration is added and verified.

## Implementation summary

- Added isolated task workspace view-model and React component with validation, no fake tasks, loading/empty/error/populated states, and create/update payload helpers.
- Added isolated inbox attention view-model and React component with active-only filtering, severity/state/type labels, linked entity labels, UI intent modeling, and no fake notifications.
- Added isolated history timeline view-model and React component with task/run/notification/entity modes, deterministic ordering, pagination cursor handling, empty/loading/error states, and redaction/sanitization of secret/raw-log-looking content.
- Added all three direct TypeScript tests to `npm run test:frontend`.
